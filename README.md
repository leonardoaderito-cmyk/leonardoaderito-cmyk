## Sistemas de gestão

- **bhub360 ERP** — ERP web, modular e multiempresa: vendas, compras, stock, contabilidade, tesouraria, RH, activos, logística, projectos e CRM, com licenciamento por módulo e 226 testes automatizados. *ASP.NET Core (.NET 10) · Blazor · SQL Server · Vue 3 · Tauri*
- **SGIdónio** — sistema de gestão de um centro de saúde: ficha do utente, caixa, venda a dinheiro, facturação, recibos, stock, despesas e relatórios; funciona offline em rede local. Inclui um sistema de laboratório (LIS) que acompanha a amostra do pedido ao laudo. *C# · SQL Server · Laravel*
- **Primavera Pagamentos** — conector que recebe pagamentos por M-Pesa, e-Mola e transferência bancária e lança o recibo no PRIMAVERA ERP V10, uma única vez por pagamento. *C# / .NET*
- **CTAGEST** — gestão documental e tramitação de expedientes para a CTA, com perfis por sector e auditoria imutável. *ASP.NET Core 8 · React · TypeScript · SQL Server*
